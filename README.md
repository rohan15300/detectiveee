# Detective Investigation System

A console-based investigation game developed in Java without interactive I/O, demonstrating object-oriented principles, modular class separation, arrays, and control structures.

## File & Module Responsibilities

- **`Suspect.java`**: Manages the suspect model, suspect data records, and array initialization.
- **`ClueManager.java`**: Handles clue array storage, collection status tracking, and duplicate prevention.
- **`Investigation.java`**: Implements suspect queries, culprit verification, and a 3-attempt accusation limit.
- **`DetectiveGame.java`**: Driver class integrating all modules with a menu switch-statement driven by predefined simulation values.
